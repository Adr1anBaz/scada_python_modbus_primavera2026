1. Descripcion General del Sistema

Este sistema SCADA controla 3 bandas transportadoras automatizadas, cada una gestionada por un PLC Horner XL4. La comunicacion se realiza mediante el protocolo Modbus TCP/IP a traves de una red Ethernet local.

Los 3 PLCs del sistema

ID Interno IP Funcion Descripcion
HORNER_2 192.168.3.132 Banda de Entrada Recibe cajas, plumas de inicio/fin, torreta, VFD
HORNER_3 192.168.3.133 Banda Central (Rotatoria) Rotador, banda lineal, torreta, sensores
HORNER_1 192.168.3.131 Banda de Salida LEDs, plumas entrada/salida, VFD, maquina de estados 
    PC (SCADA)                    Red 192.168.3.x
   ┌──────────┐                   Puerto 502 (Modbus TCP)
   │ Python   │
   │ GUI/CLI  │───────┬──────────── HORNER_2 (192.168.3.132) ── Banda Entrada
   │          │       │
   │ PySide6  │       ├──────────── HORNER_3 (192.168.3.133) ── Banda Central
   │ pymodbus │       │
   └──────────┘       └──────────── HORNER_1 (192.168.3.131) ── Banda Salida

2. Requisitos de Hardware y Software

Hardware

  • PC con puerto Ethernet (o adaptador USB-Ethernet)
  • Cable Ethernet conectado a la misma red que los PLCs (192.168.3.x)
  • Los 3 PLCs Horner XL4 encendidos y en la red

Software

  • Python 3.10 o superior (recomendado 3.12+)
  • pip (viene incluido con Python)
  • git (para clonar el repositorio)

Verificar Python

python3 --version
Python 3.12.x

Si no tienes Python:

  • Windows: Descarga desde python.org/downloads. Marca "Add Python to PATH" durante la instalacion.
  • macOS: brew install python (con Homebrew) o descarga de python.org
  • Linux: sudo apt install python3 python3-pip python3-venv

3. Instalacion Paso a Paso

Paso 1: Clonar el repositorio

git clone https://github.com/Adr1anBaz/scada_python_modbus_primavera2026.git
cd scada_python_modbus_primavera2026

Paso 2: Crear un entorno virtual (opcional pero recomendado)

Que es un entorno virtual? Es una carpeta aislada donde se instalan las dependencias del proyecto sin afectar el Python global de tu sistema. No es obligatorio, pero evita conflictos con otras aplicaciones Python. 
# Crear el entorno virtual
python3 -m venv venv

# Activarlo:
# En macOS/Linux:
source venv/bin/activate

# En Windows (CMD):
venv\Scripts\activate

# En Windows (PowerShell):
venv\Scripts\Activate.ps1

Cuando el entorno esta activo veras (venv) al inicio de tu terminal. Para desactivarlo: deactivate.

Si no quieres usar entorno virtual: Puedes instalar las dependencias directamente con pip install. Funcionara igual, solo que las librerias se instalaran globalmente.

Paso 3: Instalar dependencias

pip install -r requirements.txt

Esto instala:

  • PySide6 - Framework para la interfaz grafica (Qt6)
  • pymodbus - Libreria para comunicacion Modbus TCP

Si prefieres instalar manualmente:

pip install PySide6 pymodbus

4. Configuracion de Red

Tu PC debe estar en la misma subred que los PLCs: 192.168.3.x

Configurar IP estatica en tu PC

Parametro Valor
IP 192.168.3.100 (o cualquier IP libre en el rango .1-.254, excepto .131, .132, .133)
Mascara de subred 255.255.255.0
Gateway 192.168.3.1 (o dejar vacio)

Verificar conectividad

ping 192.168.3.131  # HORNER_1 (Salida)
ping 192.168.3.132  # HORNER_2 (Entrada)
ping 192.168.3.133  # HORNER_3 (Central)
Si no hace ping: Verifica que el cable Ethernet esta conectado, que tu IP esta en el rango correcto, y que los PLCs estan encendidos. En Windows puede ser necesario desactivar el firewall temporalmente.

6. Uso de la Interfaz Grafica (GUI)

La GUI tiene 3 pestanas, una por cada PLC. Cada pestana tiene su propio boton de conexion independiente.

Flujo general

  1. Abre la GUI
  2. Ve a la pestana del PLC que quieres controlar
  3. Presiona CONECTAR (debe cambiar a "ONLINE" en verde)
  4. Usa los botones de control

Pestana Entrada (HORNER_2)

Navegacion (modos de pantalla)

Los modos se mantienen activos (hold). Al cambiar a otro modo, el anterior se libera automaticamente.

  • Integracion - Activa T51 (pantalla modo integracion)
  • Individual - Activa T52 (pantalla modo individual)
  • Prueba - Activa T53 (pantalla modo prueba). Habilita controles de banda/plumas/torreta.
  • Salir Prueba - Libera todos los modos (regresa al menu principal)
Importante: Los botones de Banda, Plumas y Torreta solo funcionan cuando estas en Modo Prueba (T53 activo). Si no estas en prueba, apareceran deshabilitados (grises).

Control (Modo Integracion)

  • INICIO - Pulsa T99, inicia el proceso
  • STOP - Pulsa T30, frena todo el sistema

Modo Individual

  • Inicio (T99) - Inicia el proceso en modo individual
  • Stop (T33) - Stop en modo individual
  • sebListo (T995) - Banda media en posicion de recibir caja
  • sebCaja (T998) - Caja ya esta en banda media
  • UR1 (T997) - UR3 ya puso caja en banda inicial
  • UR2 (T996) - UR3 ya puede poner otra caja

Modo Prueba (solo disponible con T53 activo)

  • Banda: Izquierda (T44), Derecha (T46), Stop (T45)
  • Pluma Inicio: Sube (T5), Baja (T6)
  • Pluma Fin: Sube (T7), Baja (T8)
  • Torreta: Verde ON/OFF (T345), Amarilla ON/OFF (T346), Roja ON/OFF (T347)
  • VFD: Escribir frecuencia (R498), Leer actual (R508)

Pestana Central (HORNER_3)

Navegacion

  • Proceso - Pulsa T76
  • Integracion - Pulsa T70
  • Prueba - Toggle T51 (entra/sale del modo prueba)
  • Menu - Pulsa T53 (regresa al menu principal)
En Central, el boton Prueba es un toggle: lo presionas una vez para entrar, otra vez para salir. El sistema lee T52 para saber si estas en modo prueba.

Control (Proceso/Integracion)

  • STOP - Pulsa T49
  • Llego caja - Pulsa T24
  • Recibio B3 - Pulsa T28
  • UR3 Fin - Pulsa T79
  • B3 Lista - Pulsa T98

Modo Prueba

  • Rotador: Antihorario (T63), Horario (T55), Stop (T56)
  • Banda: Adelante (T58*), Atras (T57*), Stop (T59)
  • Torreta: Verde (T60), Amarillo (T61), Rojo (T54)

*Nota: Las direcciones de banda estan invertidas internamente (Adelante usa la senal ATRAS y viceversa) porque los motores estan cableados al reves.

Pestana Salida (HORNER_1)

Control

  • Init Proceso - Escribe bit 2 de R170 (pasa Estado 0 a 1)
  • STOP - Escribe bit 7 de R170

LEDs

  • Verde ON/OFF - R170.6
  • Amarillo ON/OFF - R170.5
  • Rojo ON/OFF - R170.4

Banda

  • Izq - Escribe 5376 en R100
  • Off - Escribe 5377 en R100
  • Der - Escribe 5378 en R100
  • T12 - Toggle del bit 12 de R170 (banda salida enclavable)

Plumas

  • Pluma Entrada: Abrir (R170.6), Cerrar (R170.8)
  • Pluma Salida: Sube toggle (R170.9), Baja toggle (R170.10)

8. Referencia Modbus - Direcciones y Offsets

OFFSET CRITICO: Las marcas T en Horner tienen un offset de -1 respecto a lo que indica la documentacion del fabricante. Este es el error mas comun al programar estos PLCs via Modbus.

Formula para T-markers (Coils)

Direccion Modbus = 5999 + N
Donde N es el numero de T-marker en la documentacion Horner

Ejemplo: Si la documentacion dice T99, la direccion real en Modbus es:

5999 + 99 = 6098
Por que el offset? El Horner XL4 numera sus T-markers desde 1 (T1, T2, T3...) pero en la interfaz Modbus las direcciones son 0-indexed. La base es 6000, pero como Horner arranca en 1, la formula real es 5999 + N. La documentacion PDF del PLC dice "T99 = direccion 6099" pero eso es INCORRECTO para Modbus TCP — el real es 6098.

Formula para Registros (R)

Direccion Modbus = 2999 + N
Donde N es el numero de registro R en Horner

Ejemplo: R498 → 2999 + 498 = 3497

Los registros (R) NO necesitan offset adicional. La formula 2999 + N funciona correctamente como esta documentada.

Formula para Bits de Registro

Los bits del registro se usan directamente (sin offset)
R170.6 = bit 6 del registro en direccion 3169
Excepcion confirmada para LEDs de SALIDA (R170): El LED verde de la documentacion dice ".7" pero en realidad es .6, el amarillo dice ".6" pero es .5. STOP dice ".6" pero es .7. Los demas bits estan correctos. Esto ya esta corregido en el codigo.

Entradas Fisicas (I)

Direccion Modbus = N - 1
I1 = 0, I2 = 1, I3 = 2, I4 = 3, I5 = 4

Salidas Fisicas (Q)

Direccion Modbus = N - 1
Q1 = 0, Q2 = 1, ..., Q8 = 7, Q9 = 8

Tabla resumen de offsets

Tipo Ejemplo Formula Direccion Real Funcion Modbus
T-marker (coil) T99 5999 + 99 6098 01/05 (Read/Write Coil)
Registro R498 2999 + 498 3497 03/06 (Read/Write Register)
Entrada (I) I4 4 - 1 3 02 (Read Discrete Input)
Salida (Q) Q8 8 - 1 7 01 (Read Coil)
Bit de registro R170.6 bit 6 de addr 3169 3169 03+06 (Read-Modify-Write)

12. Arquitectura del Codigo

horner_python_test/
├── gui_main.py              ← Interfaz grafica principal (PySide6)
├── cli_entrada.py           ← CLI para PLC Entrada
├── cli_central.py           ← CLI para PLC Central
├── cli_salida.py            ← CLI para PLC Salida
└── system/
    ├── __init__.py          ← Exporta PLCManager
    ├── config.py            ← Configuracion de IPs y puertos
    ├── constants.py         ← TODAS las direcciones Modbus
    ├── events.py            ← Sistema de eventos interno
    ├── plc_device.py        ← Abstraccion de un PLC individual
    └── plc_manager.py       ← Gestor de multiples PLCs

Flujo de datos

  1. La GUI o CLI llama al PLCManager
  2. El Manager delega al PLCDevice correcto (por ID)
  3. El Device usa pymodbus para enviar/recibir datos via TCP
  4. El PLC Horner recibe la instruccion Modbus y actua

Como agregar una nueva senal

  1. Agrega la constante en system/constants.py (aplica offset -1 para T)
  2. Agrega el boton/LED en la clase del tab correspondiente en gui_main.py
  3. Conecta el boton a una funcion que llame _pulse_coil() o _write_coil()

13. Solucion de Problemas

"No se pudo conectar al PLC"

  • Verifica que tu PC esta en la red 192.168.3.x
  • Haz ping al PLC: ping 192.168.3.131
  • Verifica que el PLC esta encendido y el cable Ethernet conectado
  • El puerto 502 debe estar libre (ningun otro software Modbus corriendo)

"ModuleNotFoundError: No module named 'PySide6'"

  • Ejecuta pip install -r requirements.txt
  • Si usas entorno virtual, asegurate de que esta activado (source venv/bin/activate)

"El boton no hace nada" / "El LED no responde"

  • Verifica que el PLC esta conectado (dice "ONLINE" en verde)
  • Para Entrada: verifica que estas en el modo correcto (Prueba para banda/plumas/torreta)
  • Usa el CLI para probar la senal directamente y descartar problema de GUI

"La banda va al reves"

  • Esto ya esta corregido en el codigo (las senales de direccion estan invertidas internamente)
  • Si persiste, intercambia los valores en constants.py para esa banda

"El scan muestra todos los valores en 0"

  • El PLC puede estar en una pantalla diferente a la esperada
  • Navega primero al modo correcto (Prueba, Integracion, etc.) antes de activar senales

"Error escribiendo registro" o "Timeout"

  • El PLC puede estar saturado. Espera 1-2 segundos y reintenta
  • Verifica que solo una instancia del programa esta conectada al PLC
  • Si persiste, desconecta y reconecta
